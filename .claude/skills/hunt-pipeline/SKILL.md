# Hunt Pipeline

## Why this rule exists

A wallet mention is not a strategy. A high PnL number is not proof. The hunter
pipeline exists to convert noisy public observations into a defensible watch
list, and later into a copy candidate.

If ranks are skipped, a single social post can become a live order. That violates
the core safety boundary and creates real loss potential.
